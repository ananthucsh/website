============================================================
PART 1 — AGENT DETAILS മാറ്റുന്നത്
============================================================

1. EDIT-MY-DETAILS.js എന്ന file-ൽ Right-click ചെയ്യുക.
2. Open with > Notepad തിരഞ്ഞെടുക്കുക.
3. Quotation marks-ന്റെ ഉള്ളിലുള്ള വിവരങ്ങൾ മാത്രം മാറ്റുക.

Example:
name: "Suraj S"

ഇത് ഇങ്ങനെ മാറ്റാം:
name: "Suresh Kumar"

താഴെ പറയുന്ന വിവരങ്ങൾ ആവശ്യാനുസരണം മാറ്റാം:

- Name, professional title and location
- Experience and languages
- Phone and WhatsApp number
- Email and Agent/Licence number
- Availability message and About paragraph
- Insurance products and descriptions

MOBILE NUMBER FORMAT:
91 + 10-digit mobile number ഉപയോഗിക്കുക.

Correct: 919876543210
Wrong: +91 98765 43210

മാറ്റങ്ങൾ പൂർത്തിയാക്കിയ ശേഷം Ctrl + S അമർത്തി save ചെയ്യുക.

WARNING:
- Quotation marks, commas, brackets, braces എന്നിവ delete ചെയ്യരുത്.
- EDIT-MY-DETAILS.js എന്ന filename മാറ്റരുത്.

============================================================
PART 5 — WEBSITE NETLIFY-ലേക്ക് UPLOAD ചെയ്യുന്നത്
============================================================

1. Login ചെയ്ത ശേഷം https://app.netlify.com/drop തുറക്കുക.
2. “Drag and drop your site” അല്ലെങ്കിൽ സമാനമായ upload area കണ്ടെത്തുക.
3. File Explorer-ൽ നിങ്ങളുടെ extracted website folder കണ്ടെത്തുക.

Folder-ന്റെ ഉള്ളിൽ കുറഞ്ഞത് ഇവ ഉണ്ടായിരിക്കണം:

index.html
EDIT-MY-DETAILS.js
agent-photo.jpg

4. ഈ complete folder mouse ഉപയോഗിച്ച് Netlify upload area-യിലേക്ക്
   drag and drop ചെയ്യുക.
5. Upload പൂർത്തിയാകുന്നത് വരെ കാത്തിരിക്കുക.
6. Netlify നൽകുന്ന live website address തുറക്കുക.

Example:
https://amazing-name-123.netlify.app

IMPORTANT:
- index.html മാത്രം upload ചെയ്യരുത്.
- ഓരോ file-ഉം പ്രത്യേകം upload ചെയ്യരുത്.
- ZIP file upload ചെയ്യരുത്.
- Extract ചെയ്ത complete folder upload ചെയ്യണം.

PART 6 — WEBSITE NAME മാറ്റുന്നത്
============================================================

Netlify ആദ്യം ഒരു random site name നൽകാം. അത് മാറ്റാൻ:

1. Netlify dashboard-ൽ നിങ്ങളുടെ website/project തുറക്കുക.
2. Site configuration അല്ലെങ്കിൽ Project configuration തുറക്കുക.
3. General > Site details / Project details ഭാഗം കണ്ടെത്തുക.
4. Change site name / Change project name തിരഞ്ഞെടുക്കുക.
5. ലഭ്യമായ ഒരു ലളിതമായ പേര് നൽകുക.

Example:
suresh-insurance-services

പുതിയ address:
https://suresh-insurance-services.netlify.app

NOTE:
- പേര് മറ്റൊരാൾ ഉപയോഗിക്കുന്നുണ്ടെങ്കിൽ മറ്റൊരു പേര് തിരഞ്ഞെടുക്കണം.
- Custom .com അല്ലെങ്കിൽ .in domain സൗജന്യമല്ല.
- ഈ workshop-ന് free netlify.app address മതിയാകും.

============================================================
COMMON PROBLEMS
============================================================

PROBLEM: Photo കാണുന്നില്ല
SOLUTION: Filename agent-photo.jpg തന്നെയാണോ എന്ന് പരിശോധിക്കുക.

PROBLEM: പഴയ വിവരങ്ങളാണ് കാണുന്നത്
SOLUTION: JS file save ചെയ്തിട്ടുണ്ടോ എന്ന് നോക്കുക; folder വീണ്ടും deploy
ചെയ്ത് Ctrl + F5 അമർത്തുക.

PROBLEM: Design കാണുന്നു, പക്ഷേ details കാണുന്നില്ല
SOLUTION: EDIT-MY-DETAILS.js folder-ൽ ഉണ്ടോയെന്നും filename മാറിയിട്ടില്ലെന്നും
പരിശോധിക്കുക.

PROBLEM: WhatsApp/Call button പ്രവർത്തിക്കുന്നില്ല
SOLUTION: Number 91 + 10 digits format-ൽ നൽകുക. +, spaces, hyphens ഒഴിവാക്കുക.

PROBLEM: Netlify page website തുറക്കുന്നില്ല
SOLUTION: Uploaded folder-ന്റെ main level-ൽ index.html ഉണ്ടെന്ന് ഉറപ്പാക്കുക.
